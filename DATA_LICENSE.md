# Data licence and attribution

**Raw data (`WyScout/`).** Soccer match event dataset collected by Wyscout and released by
L. Pappalardo and E. Massucco under the [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) licence:

- L. Pappalardo, P. Cintia, A. Rossi, E. Massucco, P. Ferragina, D. Pedreschi and F. Giannotti.
  A public data set of spatio-temporal match events in soccer competitions.
  *Scientific Data* 6, 236 (2019). https://doi.org/10.1038/s41597-019-0247-7
- Figshare collection: https://doi.org/10.6084/m9.figshare.c.4415000

The files are redistributed unchanged. `get_data.py` fetches the same files from figshare.

**Derived data (`data/`, `stage*/`).** Action values, stakes, ratings and test results computed
from the raw data by the notebooks in this repository; shared under CC BY 4.0 with the same attribution.
